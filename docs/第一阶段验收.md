## 实现但尚待人工验收

固定正交镜头、缩放/复位、按需渲染、加载超时与重试、WebGL 故障提示、销毁清理和减少动态效果已实现。没有执行浏览器自动点击、截图观感检查或设备帧率测量，不能据此宣称这些行为全部通过实机验收，也不保证 60 FPS。

用户可在私人预览中检查：模型是否显示完整；缩放和复位是否自然；九层待开放状态是否准确；断网后重新加载是否有提示和恢复。

## 已知限制

- 只有原创三层建筑管线样片，不是正式 25 层大厦，不含正式楼层和任何生活活动。
- 样片资源无外部纹理；多资源整层预算、导航和碰撞检查将在后续阶段扩充。
- Three.js 独立加载块触发 Vite 500 kB 提示；已动态导入，尚未做最终纹理压缩、按楼层分包或性能验收。
- Vite 提示未来 native 配置加载器需要 JSON import attributes；当前锁定版本正常构建。
- 工程预览无进度存储、联网游戏、账户系统或编辑器。
- 发布回执、Release 包校验与远端提交关系以 GitHub Release 中的实际回执为准；此文件记录本地验证，不提前声明托管成功。
