# 漫楼工程预览启动说明

适用版本：v0.1.1。当前只能查看模型样片和筹备中的楼层，不能进入正式楼层或控制角色。

## 从源码开发

需要 Node.js 24 LTS、npm 和 Git；只运行网页不需要安装 Blender。

1. 克隆仓库，在项目根目录运行 `git lfs install`、`git lfs pull` 取得 Blender 源文件。
2. 运行 `npm ci` 安装锁定依赖。
3. 运行 `npm run dev`，访问终端显示的本地地址（默认 http://localhost:3000/）。
4. 开发验收运行 `npm run check`，构建运行 `npm run build`。
5. 验证生产构建运行 `npm start`，访问终端显示的地址（通常 http://localhost:8787/）。

Windows PowerShell 若限制 npm.ps1，可使用同名 `npm.cmd` 命令。首次安装和本地 Worker 启动可能需要网络下载依赖。

## 从 Release 构建包启动

1. 解压 `RoamFolk-v0.1.1-build.zip` 到一个新目录。
2. 用 `Get-FileHash` 将压缩包 SHA256 与附带的校验文件核对。
3. 在解压目录执行 `npm ci`，再执行 `npm start`。
4. 打开终端显示的地址。构建包包含已编译的 Worker 和网页资源；不包含 node_modules、Blender 程序或源码工程，不能执行开发和重新构建命令。

`release-manifest.json` 记录版本、完整 Git 提交以及包内文件 SHA256。构建包需要 Node.js/npm，不是双击即可运行的 Windows EXE，也不要直接打开 HTML 文件。

## 使用与故障恢复

- 画面下方的加号、减号和复位按钮调整镜头。
- 正式九层均为待开放状态，不提供进入按钮。
- 网络或模型加载失败会显示重试按钮；WebGL 启动失败时请启用浏览器硬件加速后重试。
- 预览暂不保存进度；刷新会复位镜头。
- 仅私人 Sites 网页对所有者开放；GitHub 源码和 Release 仍是公开的。
