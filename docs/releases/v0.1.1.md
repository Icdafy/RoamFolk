# v0.1.1 — 第一阶段工程准备

将仅有计划的仓库推进为可运行的工程预览，建立后续大厦、楼层和角色开发所需的网页与 Blender 资源基础。保留 v0.1.0 文档版，不覆盖原标签。

## 新增

- Sites 脚手架、React / TypeScript / Three.js 客户端模块和私人预览配置。
- 原创三层建筑管线样片、可编辑 .blend、GLB 和资源清单；支持缩放/复位，提供加载失败与 WebGL 错误提示。
- 九个正式楼层的只读筹备状态；共享楼层、角色、交互物、存档和会话类型。
- Blender 4.5.13 LTS 本地便携环境、模型生成和导出脚本。
- Git LFS、环境诊断、资源检查、5 项自动测试、GitHub Actions 和构建包工具。
- 启动、工程、资源、发布及第一阶段验收文档。

## 验证

类型、lint、5 项测试、资源检查和生产构建通过；npm audit 在本次检查时为 0 个已知漏洞。开发与生产服务的页面和 GLB 均返回 200，模型字节一致。GLB 596,752 字节，8,432 三角面，两个稳定锚点保留。

## 已知限制

这是工程准备版，尚无正式 25 层大厦、楼层进入、角色、移动、寻路、碰撞、活动或存档。21 层等待参考图片。画面观感、按钮行为、失败恢复和 FPS 尚未做实机验收。Three.js 独立块存在体积提示。

## 构建包

下载本 Release 附件 `RoamFolk-v0.1.1-build.zip` 与 SHA256 校验文件。需要 Node.js 24 LTS；解压后执行 `npm ci`、`npm start`，访问终端显示地址。详细步骤见包内 START.md；包内 release-manifest.json 记录源提交和文件校验值。

网站保持所有者私有访问；GitHub 源码与构建附件公开。发布后的实际预览地址、完整提交及同步状态在下方发布回执补充。
