# 漫楼 RoamFolk

温暖、精致的微缩生活网页游戏：从立体大厦选择楼层，以可爱小人或拟人化物品角色自由探索、工作、摸鱼、游玩和吃饭。

- 本次已完成：保存完整开发计划、完善项目 README 和更新日志。
- 尚未实现：游戏代码、Blender 模型、可运行构建及在线试玩。
